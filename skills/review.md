# Review skill

## Apply when

A specification, plan, task set, or implementation reaches an ECC checkpoint.

## Instructions

1. Read [`memory/constitution.md`](../memory/constitution.md) and the feature's `spec.md`, `plan.md`, and `tasks.md`.
2. At **Explore/Codify** checkpoints, verify scope, testable acceptance criteria, unresolved questions, ownership, dependencies, and design simplicity.
3. At the **Commit/Deliver** checkpoint, trace each change to a task and acceptance criterion. Inspect correctness, tests, security, failure behavior, compatibility, and dependency contracts.
4. Run or inspect relevant verification. Confirm task and ledger statuses match reality.
5. Report concrete findings by severity with file/artifact locations and expected impact. Distinguish blockers from suggestions.
6. Approve only when required evidence exists; never invent evidence or widen scope during review.
